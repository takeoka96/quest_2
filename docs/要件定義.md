# 要件定義

## プロジェクト概要
DEIに関する国民の声を収集・可視化するアルゴリズムの実装

## 背景
- D：Diversity（多様性）、E：Equity（公平性）、I：Inclusion（包括性）が国・企業の競争力につながるという考えが浸透しつつある
- しかし未だトップダウンでの取り組みであり、国民ひとりひとりの声が反映された政策や企業経営に落とし込まれているとは言い難い

## 目的
- DEIに関する国民の声を収集・可視化する
- 多数決的な判断軸ではなく、少数派の意見も公平に認識できるアルゴリズムを実装する

## データソース
- 国会会議録検索システムAPI（無料・APIキー不要）
  - 国民の代表である国会議員の発言を収集
  - DEI関連キーワードで検索

## 機能要件
1. 国会議事録APIからDEI関連発言を収集する
2. テキストを数値ベクトルに変換する（埋め込み）
3. クラスタリングで意見グループを自動分類する
4. 少数派の意見も可視化できる
5. クラスタの特徴をSHAP/LIMEで説明できる

## 非機能要件
- Python 3.11.9で動作すること
- 再現性があること（乱数シード固定）
- コードにコメントがあり第三者が読めること

## 成果物
- プログラムコード（Notebook + srcモジュール）
- プレゼンテーション資料（docs/）

## 制約条件
- リポジトリサイズ150MB以内
- データはgitignore対象
