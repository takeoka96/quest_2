# 要件定義

## 1. プロジェクト概要
- プロジェクト名：DEIに関する国民の声を集めて可視化するアルゴリズムを実装せよ
- 提言先：政府・企業
- 作成者：岡田孟史
- 作成日：2026-04-27

## 2. 背景
- D：Diversity（多様性）、E：Equity（公平性）、I：Inclusion（包括性）が国・企業の競争力につながるという考えが浸透しつつある
- しかし未だトップダウンでの取り組みであり、国民ひとりひとりの声が反映された政策や企業経営に落とし込まれているとは言い難い

## 3. 解決すべき問題
- DEIに関する国民の声が体系的に収集・整理されていない
- 多数決的な判断軸では少数派の意見が埋もれてしまう
- 国民の声が政策や企業経営に反映されにくい構造になっている

## 4. 解決の方向性（仮説）
- 国民の代表である国会議員の発言をデータソースとして活用する
- 機械学習によるクラスタリングで意見グループを自動分類する
- HDBSCANを用いることで少数派の意見も独立したグループとして検出する

## 5. 成功条件
- DEI関連発言の収集・クラスタリング・可視化が完成していること
- 少数派クラスタが検出・可視化されていること
- SHAP/LIMEでクラスタの特徴が説明できていること
- プログラムコードが動作しGitLabに提出されていること

## 6. 制約条件
- 締め切り：2026年5月15日
- リポジトリサイズ：150MB以内
- 提出先：GitLab quest_2リポジトリ（mainブランチ）
- データの出典を明記すること
- APIキーはgitignore対象

## 7. 使用データ
- メイン：国会会議録検索システム（国立国会図書館提供・無料・APIキー不要）
- 取得期間：2020年〜2025年
- 取得件数：6,301件（前処理後）
