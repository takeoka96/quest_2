## アルゴリズム仕様

### Step1: データ収集
- **ソース**: 国会会議録検索システムAPI
- **エンドポイント**: `https://kokkai.ndl.go.jp/api/speech`
- **検索キーワード**: ダイバーシティ、多様性、女性活躍、包括、公平、DEI、ジェンダー、障害者、外国人労働者
- **取得期間**: 2020年〜2024年
- **取得対象**: 衆議院・参議院・委員会
- **取得項目**: 発言者名、発言内容、日付、会議名、所属会派

### Step2: 前処理
- HTMLタグ除去
- 記号・数字の正規化
- 重複発言の除去
- 短すぎる発言の除去（50文字未満）

### Step3: 埋め込み
- **モデル**: `sentence-transformers/paraphrase-multilingual-mpnet-base-v2`
- **出力**: 768次元ベクトル

### Step4: クラスタリング

まず軽量なベースラインモデルで分析を行い、
評価指標（シルエットスコア）をもとに最適なモデルを選定する。

- **評価指標**: シルエットスコア

### Step5: 可視化
- UMAPで2次元に次元削減
- クラスタごとに色分けプロット
- 少数クラスタをハイライト表示

### Step6: 解釈
- SHAP / LIMEでクラスタ分類の特徴説明

## 使用ライブラリ
| ライブラリ | 用途 |
|-----------|------|
| requests | API通信 |
| pandas | データ処理 |
| sentence-transformers | テキスト埋め込み |
| scikit-learn | K-Means・評価 |
| hdbscan | 少数派クラスタリング |
| umap-learn | 次元削減 |
| matplotlib/seaborn | 可視化 |
| shap/lime | モデル解釈 |
| japanize-matplotlib | 日本語グラフ |
